# Azeroth Survivors — Deathknight

**Deathknight 1.0.1 · For Azeroth Survivors 0.116.0 and 0.117.0 · Public test release**

Bring the Death Knight to Azeroth Survivors with Blood, Frost, and Unholy talent trees, disease-based combat, undead companions, and a full armor progression inspired by Wrath of the Lich King.

## Download and install

**[Download Deathknight 1.0.1](./AzerothSurvivors%200.117.0%20-%20Deathknight%201.0.1.zip?raw=true)**

1. Download the ZIP above and close Azeroth Survivors normally.
2. Extract the ZIP into the folder containing `AzerothSurvivors.exe`.
3. Merge the `Data` folder when prompted. When updating the mod, replace its existing files.
4. Launch `AzerothSurvivors.exe` and select **Death Knight**.

Your folder should look like this:

```text
AzerothSurvivors/
├── AzerothSurvivors.exe
├── avrt.dll
├── READ_ME.txt
└── Data/
    ├── ...existing game files...
    └── patch-D.MPQ
```

Install beside the game executable, rather than inside the `AddOns` folder. No installer or separate launcher is required. The download contains only the mod; Azeroth Survivors must already be installed.

## What’s included

- **Blood, Frost, and Unholy:** three talent trees with 42 talents, milestones, and capstones.
- **15 learnable abilities:** start with Blood Strike and build your loadout as you level.
- **Diseases:** spread Frost and Shadow damage with Icy Touch, Plague Strike, and Unholy talents.
- **Undead companions:** unlock a permanent Ghoul or a boss-prioritizing Gargoyle through talents.
- **Death Knight equipment:** progress from the basic Acherus outfit through Acherus quest armor, Valor, Bold, Doomplate, and Scourgeborne.
- **Paired weapons:** Last Laugh and Hailstorm trade direct-hit damage for faster attacks and shorter damaging-ability cooldowns. Diseases, pets, and utility cooldowns keep their existing behavior.
- **All eight supported races:** choose the race and appearance you want.
- **Class presentation:** Death Knight spell icons, armor icons, and spell effects.

## Latest changes

- Added support for Azeroth Survivors **0.117.0**, while retaining **0.116.0** support in the same download.
- Updated the class, equipment, and abilities to work with the new game version.
- Corrected the additional talent lookup table introduced in 0.117.0.
- Retained the latest balance changes: **50% more base damage** for other Death Knight attacks, diseases, pets, and weapon swings; **75% less base damage** for Howling Blast and its Rime proc compared with the previous balance.
- Kept healing amounts, defensive abilities, and cooldown values unchanged by that balance adjustment.

## Version naming

The filename lists the game version first and the mod version second:

**AzerothSurvivors 0.117.0 - Deathknight 1.0.1.zip**

This release also supports game version **0.116.0**. Later game updates may require a new mod release; compatibility with every future version is not guaranteed.

## Validation and known limits

The combined loader passed **54 Windows checks** across the two supported versions. The 0.117.0 combat hooks passed **300 automated checks** covering paired weapons, damage cooldowns, disease handling, Horn of Winter, and Obliterate targeting.

Class selection was checked in the fresh 0.117.0 install. **Final live verification of the corrected talent screen and full gameplay is still pending.** This is a public test release; please report crashes or incorrect ability behavior.

Existing saves are not included or reset by the ZIP. Keep a backup before testing a new release.
